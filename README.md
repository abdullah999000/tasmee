# مُسمِّع – مشروع فلاتر (أندرويد)

التطبيق هو نفس صفحة مُسمِّع داخل WebView، مع **جسر تعرف صوتي أصلي** (حزمة `speech_to_text`)
لأن ميزة التعرف الصوتي في المتصفح لا تعمل داخل WebView أندرويد.

## الطريقة 1: من الهاتف أو بدون تثبيت فلاتر (GitHub Actions)
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد كلها (مع المجلد المخفي `.github`).
2. افتح تبويب **Actions** ثم **Build Tasmee APK** ثم **Run workflow** (أو يبدأ تلقائياً مع كل push على `main`).
3. بعد دقائق نزّل `Tasmee-APK` من قسم Artifacts، فك الضغط، وثبّت `tasmee.apk` على الهاتف
   (فعّل «التثبيت من مصادر غير معروفة»).

## الطريقة 2: على حاسوب فيه Flutter و Android SDK
```bash
bash build_apk.sh
```
ينتج الملف `tasmee.apk`.

## ملاحظات
- يحتاج إنترنت أول مرة لتنزيل المصحف والصفحات والخطوط، وبعدها تُحفظ الصفحات التي فتحتها.
- لازم يكون عندك على الهاتف خدمة التعرف الصوتي من Google (موجودة غالباً) ومعها اللغة العربية.
  إن لم تعمل، من إعدادات الهاتف ثبّت حزمة الكلام العربية.
- قد تسمع صوت «تنبيه» من النظام كلما أعاد أندرويد تشغيل الاستماع بعد صمت، وهذا من النظام نفسه.
- أول مرة سيطلب التطبيق إذن الميكروفون: اضغط «سماح».
- الشاشة تبقى مضاءة أثناء استخدام التطبيق.
